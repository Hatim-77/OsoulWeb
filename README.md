# أصول القطع

موقع بسيط لمقارنة عروض أسعار قطع الغيار بين الشركات. ارفع ملف عرض لكل شركة (PDF أو Excel أو CSV أو نص ملصوق) ويعرض لك المقارنة بين الأسعار مع الأرخص والأغلى.

الموقع ملف واحد (`index.html`) بلا خادم وبلا بناء. بياناتك تبقى في متصفحك فقط.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub، مثلاً `usool`.
2. ارفع الملفين `index.html` و`.nojekyll` إلى الفرع الرئيسي `main`.
3. من المستودع افتح **Settings ثم Pages**.
4. تحت **Build and deployment** اختر **Deploy from a branch**، والفرع `main` والمجلد `/ (root)`، ثم **Save**.
5. بعد دقيقة تقريباً يظهر الرابط: `https://اسم-حسابك.github.io/usool/`

## ملاحظات

- قراءة ملفات PDF وExcel تحتاج اتصالاً بالإنترنت لتحميل مكتبتي pdf.js وSheetJS من cdnjs، كما تُحمَّل الخطوط من Google Fonts.
- البيانات تُحفظ في `localStorage` للمتصفح والجهاز الذي رفعت منه، فلا تظهر على جهاز آخر. استخدم زر «نسخ الجدول (CSV)» لنقل النتائج.
- الصفحة تعمل على الجوال واللابتوب والشاشات الكبيرة.
